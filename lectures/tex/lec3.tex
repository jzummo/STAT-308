\subsection*{Structure of stationary time series}
Recall the covariance estimate is given by
\[\hat\gamma_k = \frac{1}{n}\sum_{i=k+1}^n (X_i - \overline{X})(X_{i-k} - \overline{X})\]
Then \(\hat \Gamma_n\) is positive semidefinite but not consistent.

\subsection*{Covariance Structure}
Let \(\Gamma_n\) be the true covariance matrix: \(\Gamma_n = (\gamma_{j-k})_{1 \leq j, k \leq n}\). \(\Gamma_n\) is positive semidefinite and Toeplitz:
\[\Gamma_n = 
\begin{bmatrix}
\gamma_0 & \gamma_1 & \cdots & \gamma_{n-1} \\
\gamma_1 & \gamma_0 & \cdots & \gamma_{n-2} \\
\vdots & \vdots & \ddots & \vdots \\
\gamma_{n-1} & \gamma_{n-2} & \cdots & \gamma_0
\end{bmatrix}\]
Note that \(\gamma_i = \gamma_{-i}\) due to symmetry. What are the eigenvalues of \(\Gamma_n\)? Define \(f(\theta) = \sum_{k=-\infty}^\infty \gamma_k e^{ik\theta}\) for \(0 \leq \theta \leq 2\pi\). We call \(f\) the \emph{spectral density function}. The eigenvalues of \(\Gamma_n\) are approximately \(\{ f(\theta) : 0 \leq \theta \leq 2\pi \}\).

Consider the limiting case where \(n = \infty\). Let \(\Gamma\) be the infinite covariance matrix and \(\one\) the infinite vector of all ones. By performing matrix multiplication, we see
\[\Gamma \one = \left(\sum_{k=-\infty}^\infty \gamma_k\right) \one\]
So \(\sum_{k=-\infty}^\infty \gamma_k = f(0)\) is an eigenvalue of \(\Gamma\). Similarly,
\[f(\pi) = \sum_{k=-\infty}^\infty (-1)^k \gamma_k\]
Let \(\mathbf{x} = (\cdots -1, 1, -1, \dots)\). Then
\[\Gamma \mathbf{x} = \left(\sum_{k=-\infty}^\infty (-1)^k \gamma_k\right) \mathbf{x} = f(\pi)\mathbf{x}\]
\textbf{Homework}: Verify the connection between spectral density and eigenvalues above via simulation. Set \(n = 1000\) and use an AR(1) process.

How to estimate \(\Gamma_n\) consistently? It can be shown that, \(\rho(\hat \Gamma_n - \Gamma_n) \asymp \log n\), so consistency fails. If \(k\) is large, then \(\hat \gamma_k\) is a bad estimate of \(\gamma_k\) because of limited data. Yet \(\sqrt{n}(\hat \gamma_k - \E[\hat\gamma_k]) \cd \N(0, \sigma_k^2)\). For large \(k\), instead we should estimate \(\tilde \gamma_k \equiv 0\). The MSE is
\[\text{MSE}(\tilde\gamma_k) = (0 - \gamma_k)^2 = \gamma_k^2 = \rho^{2k}\]
For an AR(1) process \(X_i = \rho X_{i-1} + \epsilon_i\), we have \(\gamma_k \approx \rho^k\). Then
\[\text{MSE}(\hat \gamma_k) = \Var[\hat\gamma_k] + \text{bias}^2\]
If \(k \geq \rho \log n\), then \(\tilde \gamma_k\) is a better estimator (in terms of MSE) than \(\hat \gamma_k\). Set
\[\tilde \Gamma_n = (\hat\gamma_{j-h}\one[|j - h| \leq k])\]
Where \(k = \rho \log n\).

\textbf{Homework}: Show that \(\rho(\tilde \Gamma_n - \Gamma_n) \rightarrow 0\).

We can use other kernelized covariance estimators:
\[\Gamma_n^w = (\hat \gamma_{j-k} w_{j-k})_{1 \leq j, k \leq n}\]
where \(w\) is variously a box kernel, triangular kernel, Gaussian kernel, Epanechnikov kernel, etc. We can write these estimate as
\[\Gamma_n^w = \Gamma_n \odot W,\]
where the martrix \(W\) is determined by our choice of kernel.

\textbf{Theorem} (Schur): If \(A, B \succeq 0\), then \(A \odot B \succeq 0\).

\textbf{Theorem}: A matrix \(A\) is positive semidefinite iff there exists a random vector \(X\) such that \(A = \Cov[X]\).

We can take the random variable \(X\) to be Gaussian. If \(A\) is an \(n \times n\) matrix, the \(X\) will be an \(n\)-vector.

\textbf{Proof of Schur}: Let \(A = \Cov[X]\) and \(B = \Cov[Y]\). Let \(X, Y\) be centered WLOG. Define
\[Z = (X_1 Y_1, \dots, X_n Y_n)\]
and let \(X, Y\) be independent. Then
\[\Cov[Z_i, Z_j] = \E[Z_i Z_j] = \E[X_i X_j Y_i Y_j] = \E[X_i X_j]\E[Y_i Y_j] = A_{ij}B_{ij}\]
So \(\Cov[Z] = A \odot B\).
